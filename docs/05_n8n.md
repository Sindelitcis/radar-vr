# Orquestração no n8n

**Projeto:** Radar VR
**Disciplina:** AI Factory, Etapa 1 (PUCPR)
**Versão do n8n:** 2.35.7

---

## 1. Papel do fluxo

O n8n agenda e dispara a edição, e expõe as manchetes publicadas como itens
estruturados para encadeamento posterior.

A lógica do boletim, que envolve série temporal, detecção de eventos e memória
de publicação, permanece em Python. Reimplementá-la em nós JavaScript criaria
duas fontes da mesma regra, com risco de divergirem. O fluxo faz o que a
ferramenta faz bem: agendamento, execução e transporte de dados.

## 2. Nós

```
Executar manualmente ─┐
                      ├─► Publicar edição ─► Ler planilha ─► Converter
Agendamento 09h ──────┘    (jornal.py)       (CSV)           em itens
                                                                 │
                                                                 ▼
                                                    Manchetes desta edição
```

| Nó | Tipo | Função |
|---|---|---|
| Executar manualmente | Manual Trigger | disparo sob demanda |
| Agendamento diário 09h | Schedule Trigger | `0 9 * * *` |
| Publicar edição | Execute Command | executa `executar_jornal.cmd` |
| Ler planilha publicada | Read/Write File | lê `data/jornal_vr.csv` |
| Converter em itens | Extract From File | converte o CSV em itens |
| Manchetes desta edição | Code | isola a execução mais recente |

O CSV acumula todas as edições; o último nó filtra pelo maior `publicada_em`.

O arquivo é gravado com BOM para que o Excel reconheça a acentuação, o que faz
a primeira coluna chegar como `﻿publicada_em`. As chaves são normalizadas
antes da leitura.

## 3. Execução

```
executar_n8n.cmd run      executa o fluxo, sem interface
executar_n8n.cmd ui       abre a interface em http://localhost:5678
executar_n8n.cmd import   reimporta o fluxo a partir do JSON
```

`ui` e `run` não coexistem: ambos ocupam a porta 5679 do task broker.

## 5. Configuração exigida pelo n8n 2

O n8n 2 restringe por padrão dois comportamentos necessários ao fluxo. Ambas as
alterações estão em `executar_n8n.cmd` e são limitadas à instância local.

| Variável | Padrão | Valor adotado | Motivo |
|---|---|---|---|
| `NODES_EXCLUDE` | `['n8n-nodes-base.executeCommand', 'n8n-nodes-base.localFileTrigger']` | `[]` | O nó Execute Command dispara o pipeline. É desabilitado por padrão porque executa comando arbitrário no host; a instância roda apenas em localhost, sem exposição de rede |
| `N8N_RESTRICT_FILE_ACCESS_TO` | `~/.n8n-files` | pasta do projeto | O fluxo lê o CSV publicado. A restrição é redirecionada, não removida: o n8n segue impedido de ler qualquer outro caminho |
